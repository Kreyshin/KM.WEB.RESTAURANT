# Sala

Dónde se sienta la gente.

## Salones

Las zonas físicas del local: salón principal, terraza, barra, privado. Ordenan el plano y agrupan las mesas.

Un salón también es la referencia de las **áreas**: la cocina fría de la terraza y la del salón pueden llamarse igual porque están en salones distintos.

## Mesas

Cada mesa tiene código, capacidad, forma y posición en el plano.

### Los estados

| Estado      | Qué significa                            |
| ----------- | ---------------------------------------- |
| Libre       | Disponible para sentar                   |
| Ocupada     | Con comensales                           |
| Reservada   | Comprometida para una reserva            |
| En limpieza | Se está preparando para rotar            |
| Inactiva    | Fuera de uso: avería, reforma, temporada |

«En limpieza» no es un adorno: en un servicio con lista de espera, la diferencia entre una mesa libre y una que aún se está limpiando son diez minutos de rotación.

### El plano

Las mesas colocadas donde están de verdad, con su estado en color, glifo y texto. Responde lo que una lista no puede: _¿tengo algo para seis cerca de la ventana?_.

### Unir mesas

Dos o más mesas pueden unirse para un grupo grande: se atienden como una sola cuenta mientras dure. Al separarlas, cada una vuelve a ser independiente.

### Asignar mesero

Cada mesa puede tener su mesero del turno, que es como se reparte la sala y como se sabe a quién pedirle cuenta.
